Understand the basic mathematical model underlying the operation of a single neuron

2.1Trask+
Nu

A single neuron

A neuron multiplies each input by a weight, adds them up (a weighted sum), and usually passes the result through an activation function.

Ch 3 · p 25–30Ch 6 · p 121–123Ch 9 · p 162

In Trask's simplest network, a neural network is just one or more weights that you multiply by the input to make a prediction. Ch 3 · p 25

The input is information and the weight is knowledge: the network uses the knowledge in its weights to interpret the information in the input. Every network in the book works this way. Ch 3 · p 26

one input:   prediction = input × weight
many inputs: prediction = Σ inputi × weighti = input · weights

A weight above 1 amplifies the input, below 1 shrinks it, a negative weight flips it. Trask calls each weight a volume knob. Adding up the scaled inputs is the weighted sum, also called the dot product. Ch 3 · p 26, 30

From chapter 6 on, the weighted sum goes through an activation function such as relu (negative values become 0). Without one, stacking neurons adds no power. Ch 6 · p 121–123 Ch 9 · p 162

def neuron(inputs, weights):
    total = 0
    for x, w in zip(inputs, weights):
        total += x * w          # weighted sum
    return max(0, total)        # relu activation

print(neuron([8.5, 0.65, 1.2], [0.1, 0.2, 0.0]))   # 0.98
Not in Trask
y = f(w · x + b)

Most textbooks add a bias b to the weighted sum, so the neuron can shift its output even when every input is 0. Think of it as a weight on an extra input that is always 1. Trask mostly leaves it out to keep the code small.

SU2 · 2.2

Describe a single-input, single-output network

2.2Trask
Si

Single input, single output

One input, one weight, one prediction: prediction = input × weight.

Ch 3 · p 24–27

Trask's first network predicts whether a baseball team will win from the average number of toes per player. With a weight of 0.1 and an input of 8.5, it predicts 0.85. Ch 3 · p 25

weight = 0.1

def neural_network(input, weight):
    prediction = input * weight
    return prediction

number_of_toes = [8.5, 9.5, 10, 9]
print(neural_network(number_of_toes[0], weight))   # 0.85

Notice: the network knows only what you give it. It doesn't remember the previous game's input. Ch 3 · p 26

A single weight can only scale the input: weight 2 doubles it, 0.01 divides it by 100. So this network can only model 'more input → proportionally more (or less) output'. Ch 3 · p 26

SU2 · 2.3

Describe a multiple-input, single-output network

2.3Trask
Mi

Multiple inputs, single output

Several inputs, one output: multiply each input by its own weight and add them up.

Ch 3 · p 28–35

The number of toes alone isn't a great predictor. Feeding the network the win/loss record and fan count too lets it combine information for a better-informed prediction. Ch 3 · p 28

Each input passes through its own volume knob, and the local predictions are added together: a weighted sum, or dot product. Ch 3 · p 30

pred = 8.5×0.1 + 0.65×0.2 + 1.2×0.0 = 0.85 + 0.13 + 0 = 0.98
def w_sum(a, b):
    assert len(a) == len(b)
    output = 0
    for i in range(len(a)):
        output += a[i] * b[i]
    return output

weights = [0.1, 0.2, 0]            # toes, win/loss, fans
input = [8.5, 0.65, 1.2]           # first game of the season
print(w_sum(input, weights))       # 0.98

The weights show what the network thinks matters. A weight of 0 (fans) means 'ignore this input'; a large positive weight means a strong positive link. Ch 3 · p 30–34

NumPy does the same in one call: input.dot(weights). Ch 3 · p 35

SU2 · 2.4

Describe a single-input, multiple-output network

2.4Trask
Sm

Single input, multiple outputs

One input, several outputs: the same input is multiplied by a different weight for each output.

Ch 3 · p 36–37

Using only the win/loss record, the network predicts three things: the share of players who are hurt, whether the team wins, and whether the players are sad. Ch 3 · p 36

The three predictions are completely separate. It behaves like three independent single-weight networks that happen to share the same input. Ch 3 · p 36

[hurt, win, sad] = 0.65 × [0.3, 0.2, 0.9] = [0.195, 0.13, 0.585]
def ele_mul(number, vector):
    output = [0, 0, 0]
    for i in range(len(vector)):
        output[i] = number * vector[i]     # same input, different weight
    return output

weights = [0.3, 0.2, 0.9]                  # hurt?, win?, sad?
print(ele_mul(0.65, weights))

Elementwise multiplicationMultiply a number (or vector) by each element in turn.
Independent outputsEach output has its own weight and doesn't affect the others.
SU2 · 2.5

Describe a multiple-input, multiple-output network

2.5Trask
Mm

Multiple inputs, multiple outputs

Several inputs, several outputs: each output does its own weighted sum of all the inputs. The weights form a matrix.

Ch 3 · p 38–46

Every input node is connected to every output node. Trask recommends thinking of it as three independent weighted sums, one per output. Ch 3 · p 40

hurt = 8.5×0.1 + 0.65×0.1 + 1.2×(−0.3) = 0.555
win  = 8.5×0.1 + 0.65×0.2 + 1.2×0.0    = 0.98
sad  = 8.5×0.0 + 0.65×1.3 + 1.2×0.1    = 0.965

A list of weight vectors is a matrix, and doing a weighted sum with every row is vector-matrix multiplication. Ch 3 · p 41

import numpy as np
weights = np.array([[0.1, 0.1, -0.3],     # hurt?
                    [0.1, 0.2,  0.0],     # win?
                    [0.0, 1.3,  0.1]])    # sad?
input = np.array([8.5, 0.65, 1.2])
print(weights.dot(input))                 # [0.555 0.98 0.965]

Stacking: predicting on predictions

The outputs of one network can be the inputs of another. The values in the middle form a hidden layer. This is the first step towards deep networks. Ch 3 · p 42

Shapes must line up: a (a, b) matrix dotted with a (b, c) matrix gives (a, c); .T flips rows and columns. Ch 3 · p 46

Everything in the chapter is forward propagation: activations flow forward from input to prediction. Ch 3 · p 46
